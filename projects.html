LiveKit AI Voice Agent

Real-Time Voice AI for Dental Scheduling · AssignCorp

An AI voice assistant for a dental office, built on LiveKit's real-time communication framework so callers can talk to it like they would a front-desk staff member. The Python backend integrates OpenAI's APIs for speech-to-text and LLM-driven dialogue, turning a phone conversation into a structured scheduling action.

  • Architected and developed the AI voice assistant using the LiveKit real-time communication framework.
  • Built Python backend services integrating OpenAI APIs for speech-to-text, LLM-driven dialogue, and automated appointment workflows.
  • Designed scalable API pipelines to log calls, manage scheduling, and integrate with external systems using n8n automation.
  • Containerized services with Docker for reproducible deployments and local testing across distributed components.
  • Implemented conversational logic to handle scheduling, rescheduling, and cancellation scenarios aligned with real business workflows.

NasomEATR

Real-Time Speech Analysis Platform

First place, Informatics category at UC Irvine's ICS Project Expo, 2025.

A mobile app paired with wireless hardware to process acoustic signals in real time. It computes nasalance scores, a measure speech-language pathologists use to assess the balance of nasal and oral airflow during speech, and stores the results as structured datasets for further analysis.

  • Architected and built a mobile app integrating wireless hardware communication for real-time acoustic signal processing.
  • Designed data pipelines to compute nasalance scores and store structured speech-analysis datasets.
  • Optimized low-latency data transmission between device and mobile system.
